# 하루 5분 시편 디지털 필사 (Psalms Pilsa)

말씀 한 구절을 손으로 옮겨 적으며 하루 5분을 조용히 쉬어 가는 웹 앱입니다.
설치도 회원가입도 없이 브라우저에서 바로 열리고, 모든 동작은 기기 안에서만 이루어집니다.

**▶ 바로 열기: https://goodphotos.github.io/psalms-pilsa/**

## 무엇을 할 수 있나요

- **한 글자씩 필사** — 화면을 탭하고 타자를 치면 구절이 한 자씩 채워집니다. 틀린 글자는 붉게 표시되고, 진행률이 게이지로 보입니다.
- **타자기 소리** — 실제 타자기처럼 톤이 바뀌는 소리를 켜고 끌 수 있습니다.
- **화면 모드** — 밝은 종이색 / 어두운 밤색 두 가지 테마.
- **오늘의 필사 카드** — 구절을 다 옮기면 인스타그램·카카오톡에 올릴 수 있는 카드 이미지(PNG)로 저장됩니다.
- **구절 이동** — 이전 / 다음 구절 버튼으로 넘겨 봅니다.

## 지금 담긴 구절

시편 23편 1–2절, 시편 121편 1–2절 (프로토타입 4구절).
구절 목록은 `index.html` 안의 `verses` 배열에 있습니다.

## 기술

- 파일 하나(`index.html`)에 HTML·CSS·JavaScript를 모두 담은 정적 웹 앱
- 서버도 데이터베이스도 없음. 저장되는 정보 없음
- 글꼴: 구운 바탕(Google Fonts), Pretendard
- 호스팅: GitHub Pages
